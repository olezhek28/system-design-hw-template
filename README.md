# Домашки курса System Design

Здесь ты делаешь домашки курса: пять design doc'ов и пять схем, по одной на неделю.
К концу курса это твоё портфолио — пять разобранных задач, которые не стыдно
показать и по которым удобно готовиться перед собесом.

Условия домашек живут **на платформе**, не здесь. В этом репозитории — только каркас,
куда ты пишешь решение.

| Неделя | Папка | Домашка |
|---|---|---|
| 1. Алгоритм интервью + первый слой архитектуры | `hw-01/` | Экстренная выкатка: 50 млн устройств за 6 часов |
| 2. Ядро баз данных | `hw-02/` | Списать деньги 1,2 млрд раз в сутки и не уйти в минус |
| 3. Кэш, очереди и устойчивость | `hw-03/` | Чёрная пятница в Ozon: пик ×20 и живые цены |
| 4. Первые боевые кейсы | `hw-04/` | Twitch: прямой эфир на 5 млн зрителей и живой чат |
| 5. Сложные кейсы + поведение на собесе | `hw-05/` | Airbnb: последнее свободное жильё и поиск по карте |

## Настройка — один раз, пять минут

Схемы рисуем в [Excalidraw](https://excalidraw.com). Не потому, что красиво, а потому
что на реальном собесе тебе дадут ровно такую доску: прямоугольники, стрелки, подписи
и таймер. Чем привычнее инструмент, тем меньше он забирает внимания на секции.

**Если у тебя VS Code** (рекомендую — рисуешь не выходя из репозитория):

1. Поставь расширение [Excalidraw](https://marketplace.visualstudio.com/items?itemName=pomdtr.excalidraw-editor).
2. Всё. Файлы `*.excalidraw.png` теперь открываются как холст, `Cmd+S` сохраняет.

**Если не хочешь ставить ничего:** нажми `.` на странице своего репозитория на
GitHub — откроется `github.dev`, тот же VS Code в браузере. Расширение ставится и туда,
схема правится прямо там, коммит уходит оттуда же.

**Если без VS Code совсем:** работаешь на [excalidraw.com](https://excalidraw.com) в браузере.
Открываешь файл схемы через меню → «Открыть», рисуешь, сохраняешь обратно тем же
«Сохранить в файл» поверх старого. В Chrome и Edge браузер сохранит прямо в тот же
файл в папке репозитория, без «Загрузок».

**Библиотека компонентов.** В VS Code она подключается сама: репозиторий несёт
настройку `excalidraw.workspaceLibraryPath`, и коробки уже стоят в панели библиотеки —
CDN, балансировщик, шлюз, база, реплика, шард, кэш, очередь, воркер. В браузере на
excalidraw.com подключи руками: перетащи `excalidraw/sd-stencils.excalidrawlib` на холст.

Цвет кодирует слой:

- 🔵 синий — вход и сеть (DNS, CDN, LB, gateway)
- 🟢 зелёный — вычисление (сервисы, воркеры)
- 🟡 жёлтый — хранение (базы, реплики, шарды, кэш, объектное хранилище)
- 🔴 красный — асинхрон (очереди, брокеры, шина событий)

Это не украшательство: ментор с одного взгляда видит, где у тебя синхронный путь, а где
асинхронный, и разбор начинается с сути, а не с расшифровки твоих коробок.

## Как делать домашку

```bash
git switch -c hw-01        # ветка на домашку
```

В папке недели два файла:

- `design.md` — скелет по пяти шагам курса. Заполняешь по порядку, разделы не выкидываешь.
- `diagram.excalidraw.png` — схема. Файла ещё нет, создай его сам. В VS Code это
  обычный New File с именем **ровно таким**, с двойным расширением: пустой файл с этим
  именем открывается холстом Excalidraw, а не текстом. В браузере — «Сохранить как» с тем
  же именем. Такой PNG хранит
  внутри себя исходник: GitHub покажет его картинкой прямо в pull request, а Excalidraw
  откроет обратно на редактирование. Один файл, а не «исходник плюс экспорт», которые
  через две правки разъедутся.

На схему закладывай минут пятнадцать. Оценивается не красота, а то, читается ли по
ней путь запроса.

Коммить по ходу, а не одним «done» в конце: история коммитов показывает порядок твоих
мыслей, и ментору есть за что зацепиться на разборе.

## Как сдать

1. `git push -u origin hw-01`
2. Открой pull request `hw-01` → `main` **в своём репозитории**. Чек-лист подставится сам.
3. На платформе, на странице домашки, нажми «Сдать». Ссылку вставлять не нужно —
   платформа сама подтянет твой pull request.

## Как проходит разбор

Ментор открывает pull request: схема видна прямо в файле, текст он комментирует
построчно. Замечания приходят туда же, в комментарии.

Дальше правишь у себя, пушишь в ту же ветку — pull request обновляется сам,
пересдавать ничего не нужно. Когда домашка принята, влей ветку в свой `main`:
`main` — это твоя папка с принятыми работами.

## Частые вопросы

**Схема не открылась в Excalidraw.** Проверь имя: `diagram.excalidraw.png`, а не
`diagram.png`. Обычный PNG — просто картинка, исходника внутри у него нет.

**Можно рисовать в другом инструменте?** Можно, но тогда положи рядом и исходник, и
экспорт, и следи, чтобы они не разъезжались. Excalidraw избавляет от этой заботы, и на
собесе доска будет всё равно такая.

**Репозиторий приватный?** Да, видишь его только ты и твой ментор. Ментору доступ
выдаёт платформа, руками никого добавлять не надо.
