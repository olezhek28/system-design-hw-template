# Домашки курса System Design

Пять домашек, по одной на неделю. В папке недели ты пишешь решение и кладёшь рядом схему.
К концу курса набирается пять разобранных задач, по которым удобно готовиться к собесу.

Условия домашек лежат на платформе. Тут только каркас под решение.

- `hw-01` Экстренная выкатка: 50 млн устройств за 6 часов
- `hw-02` Списать деньги 1,2 млрд раз в сутки и не уйти в минус
- `hw-03` Чёрная пятница в Ozon: пик ×20 и живые цены
- `hw-04` Twitch: прямой эфир на 5 млн зрителей и живой чат
- `hw-05` Airbnb: последнее свободное жильё и поиск по карте

## Чем рисуем

Схемы рисуем в Excalidraw. Причина простая: на собесе тебе дадут ровно такую доску,
прямоугольники со стрелками и таймер. Чем привычнее инструмент, тем меньше он забирает
внимания на секции.

Два рабочих пути, бери любой.

В браузере: заходишь на excalidraw.com, рисуешь, сохраняешь в папку недели. Ставить
ничего не надо.

В VS Code: ставишь расширение Excalidraw, и файлы схем открываются холстом прямо в
редакторе. Сохранение по Cmd+S, из репозитория выходить не нужно.

В Cursor расширение не работает: висит минутами и файл так и не открывает, потому что в
его магазине лежит версия годовой давности. Сидишь в Cursor, рисуй в браузере.

## Библиотека коробок

В `excalidraw/sd-stencils.excalidrawlib` лежат готовые компоненты: CDN, балансировщик,
шлюз, база, реплика, шард, кэш, очередь, воркер. В браузере перетащи этот файл на холст,
и они появятся в панели слева. В VS Code подключать не надо, репозиторий несёт нужную
настройку.

Цвет у коробки не для красоты, он говорит про слой:

- синий: вход и сеть, то есть DNS, CDN, балансировщик, шлюз
- зелёный: вычисление, сервисы и воркеры
- жёлтый: хранение, базы и реплики, шарды, кэш, объектное хранилище
- красный: асинхрон, очереди и брокеры
- чёрный: то, что вне твоей системы, клиент или чужой сервис

Ментор смотрит на такую схему и сразу видит, где синхронный путь, а где он уходит в
асинхрон. Разбор начинается с сути, а не с расшифровки твоих коробок.

## Как сохранять схему

Схема живёт в репозитории одним файлом `diagram.excalidraw.png`. Это картинка, внутри
которой спрятан исходник: GitHub покажет её прямо в pull request, а Excalidraw откроет
обратно на правку. Поэтому не бывает пары «исходник и экспорт», которая через две правки
разъедется.

В VS Code думать не о чем. Создаёшь файл с именем `diagram.excalidraw.png`, рисуешь,
жмёшь Cmd+S. Исходник ложится внутрь картинки сам.

В браузере: меню, дальше `Экспортировать изображение`, включить `Встроить сцену`, нажать
PNG и сохранить в папку недели под тем же именем. Вернуться к правке через меню и
`Открыть`.

Переключатель `Встроить сцену` выключен по умолчанию, и это единственные грабли
браузерного пути. Забудешь включить, получится обычная картинка, которую уже не
поправишь. Проверь сразу после первого сохранения: открой файл обратно. Открылся схемой,
значит всё верно.

## Как делать домашку

Заводишь ветку на домашку:

```bash
git switch -c hw-01
```

В папке недели лежит `design.md`, скелет решения по шагам с курса. Схему кладёшь рядом.
На рисование закладывай минут пятнадцать: смотрят не на красоту, а на то, читается ли по
схеме путь запроса. Нужный уровень детализации видно на примере в `example`, там разобрана
раздача обновления из первой домашки.

Коммить по ходу, а не одним `done` в конце. По истории коммитов видно порядок твоих
мыслей, и ментору есть за что зацепиться на разборе.

## Как сдать

1. `git push -u origin hw-01`
2. Открой pull request `hw-01` в `main` у себя в репозитории. Чек-лист подставится сам.
3. На платформе, на странице домашки, нажми «Сдать». Ссылку вставлять не нужно, платформа
   сама подтянет твой pull request.

## Как проходит разбор

Ментор открывает pull request. Схема видна прямо в файле, текст он комментирует построчно,
замечания приходят туда же.

Дальше правишь у себя и пушишь в ту же ветку. Pull request обновляется сам, пересдавать
ничего не надо. Когда домашку приняли, влей ветку в свой `main`: там копятся принятые
работы.

## Частые вопросы

Схема не открылась обратно. Значит при экспорте из браузера был выключен `Встроить сцену`
и внутри картинки нет исходника. Придётся рисовать заново, поэтому проверяй сразу после
первого сохранения. В VS Code такой ошибки не бывает.

Файл `.excalidrawlib` открывается текстом. Так и должно быть, это библиотека коробок, а не
рисунок. Её не открывают, её перетаскивают на холст.

Расширение в Cursor висит и не открывает файл. Известная беда, не чини. Рисуй в браузере.

Можно рисовать в другом инструменте? Можно, но тогда клади рядом исходник и экспорт и
следи, чтобы они не разъезжались. С Excalidraw этой заботы нет, а на собесе доска будет
всё равно такая.

Репозиторий приватный? Да. Видишь его только ты и твой ментор, доступ ментору выдаёт
платформа.
