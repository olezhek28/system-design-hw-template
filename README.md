# Домашки курса System Design

Здесь ты делаешь домашки курса: пять design doc'ов и пять схем, по одной на неделю.
К концу курса это твоё портфолио — пять разобранных задач, которые не стыдно
показать и по которым удобно готовиться перед собесом.

Условия домашек живут **на платформе**, не здесь. В этом репозитории — только каркас,
куда ты пишешь решение.

| Неделя | Папка | Домашка |
|---|---|---|
| 1. Алгоритм интервью + первый слой архитектуры | `hw-01/` | Экстренная выкатка: 50 млн устройств за 6 часов |
| 2. Ядро баз данных | `hw-02/` | Списать деньги 1,2 млрд раз в сутки и не уйти в минус |
| 3. Кэш, очереди и устойчивость | `hw-03/` | Чёрная пятница в Ozon: пик ×20 и живые цены |
| 4. Первые боевые кейсы | `hw-04/` | Twitch: прямой эфир на 5 млн зрителей и живой чат |
| 5. Сложные кейсы + поведение на собесе | `hw-05/` | Airbnb: последнее свободное жильё и поиск по карте |

## Чем рисуем

Схемы рисуем в [Excalidraw](https://excalidraw.com) — прямо в браузере, ставить ничего
не надо. Выбор не про красоту: на реальном собесе тебе дадут ровно такую доску —
прямоугольники, стрелки, подписи и таймер. Чем привычнее инструмент, тем меньше он
забирает внимания на секции.

**Библиотека коробок.** Перетащи `excalidraw/sd-stencils.excalidrawlib` на холст — в
панели слева появятся готовые компоненты: CDN, балансировщик, шлюз, база, реплика, шард,
кэш, очередь, воркер. Один раз перетащил — остаётся для всех твоих схем.

Цвет кодирует слой:

- 🔵 синий — вход и сеть (DNS, CDN, LB, gateway)
- 🟢 зелёный — вычисление (сервисы, воркеры)
- 🟡 жёлтый — хранение (базы, реплики, шарды, кэш, объектное хранилище)
- 🔴 красный — асинхрон (очереди, брокеры)
- ⚫ чёрный — вне твоей системы (клиент, чужой сервис)

Это не украшательство: ментор с одного взгляда видит, где синхронный путь, а где он
уходит в асинхрон, и разбор начинается с сути, а не с расшифровки твоих коробок.

Пример нужного уровня детализации — в папке `example/`.

## Как сохранять схему

Схема лежит в репозитории **одним файлом** `diagram.excalidraw.png`. Это PNG, внутри
которого спрятан исходник: GitHub покажет его картинкой прямо в pull request, а
Excalidraw откроет обратно на редактирование. Поэтому не бывает «исходник плюс экспорт»,
которые через две правки разъедутся.

**Сохранить:** меню (☰) → «Экспортировать изображение» → **включить «Встроить сцену»** →
кнопка PNG → сохранить в папку недели под именем `diagram.excalidraw.png`.

> Переключатель «Встроить сцену» по умолчанию **выключен**. Забудешь включить —
> получится обычная картинка, которую потом уже не поправишь. Проверить просто: открой
> сохранённый файл обратно через меню → «Открыть». Открылся схемой — всё верно.

**Вернуться к правке:** меню (☰) → «Открыть» → выбрать свой `diagram.excalidraw.png`.

## Как делать домашку

```bash
git switch -c hw-01        # ветка на домашку
```

В папке недели лежит `design.md` — скелет по пяти шагам курса. Заполняешь по порядку,
разделы не выкидываешь. Схему кладёшь рядом, файлом `diagram.excalidraw.png`.

На схему закладывай минут пятнадцать. Оценивается не красота, а то, читается ли по ней
путь запроса.

Коммить по ходу, а не одним «done» в конце: история коммитов показывает порядок твоих
мыслей, и ментору есть за что зацепиться на разборе.

## Как сдать

1. `git push -u origin hw-01`
2. Открой pull request `hw-01` → `main` **в своём репозитории**. Чек-лист подставится сам.
3. На платформе, на странице домашки, нажми «Сдать». Ссылку вставлять не нужно —
   платформа сама подтянет твой pull request.

## Как проходит разбор

Ментор открывает pull request: схема видна прямо в файле, текст он комментирует
построчно. Замечания приходят туда же, в комментарии.

Дальше правишь у себя, пушишь в ту же ветку — pull request обновляется сам,
пересдавать ничего не нужно. Когда домашка принята, влей ветку в свой `main`:
`main` — это твоя папка с принятыми работами.

## Если хочешь рисовать не выходя из редактора

Для VS Code есть [расширение Excalidraw](https://marketplace.visualstudio.com/items?itemName=pomdtr.excalidraw-editor):
файлы `.excalidraw.png` открываются холстом прямо в редакторе, сохранение по `Cmd+S`.
Репозиторий уже несёт настройку `excalidraw.workspaceLibraryPath`, так что библиотека
коробок там подхватывается сама.

Оговорка: расширение тащит в редактор webview на 21 МБ и заводится не везде — в Cursor
у нас оно висело минутами и так и не открыло файл. Если у тебя так же, не воюй с ним:
браузерный путь выше полноценный, им и пользуйся.

## Частые вопросы

**Схема не открылась обратно.** Значит при экспорте был выключен «Встроить сцену» —
внутри картинки нет исходника. Перерисовывать придётся заново, поэтому проверяй сразу
после первого сохранения.

**Файл `.excalidrawlib` открывается текстом.** Так и должно быть: это библиотека коробок,
а не рисунок. Её не открывают, её перетаскивают на холст.

**Можно рисовать в другом инструменте?** Можно, но тогда клади рядом и исходник, и
экспорт, и следи, чтобы они не разъезжались. Excalidraw избавляет от этой заботы, и на
собесе доска будет всё равно такая.

**Репозиторий приватный?** Да, видишь его только ты и твой ментор. Ментору доступ
выдаёт платформа, руками никого добавлять не надо.
