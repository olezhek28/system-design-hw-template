# Пример схемы

`diagram.excalidraw` — эталонная схема первой домашки: раздача обновления. Смотри на неё
не как на образец красоты, а как на образец **уровня детализации**, которого достаточно.

Что на ней видно с одного взгляда и что должно быть видно на твоей:

- **два пути разведены явно** — тяжёлая раздача пакета идёт через CDN мимо origin, а
  постоянный фон check-in-запросов идёт своим путём через балансировщик и шлюз;
- **цвет говорит про слой** — синее это вход и сеть, зелёное считает, жёлтое хранит;
- **коробок восемь, а не двадцать** — на схеме только то, что участвует в решении задачи.

Открой файл в VS Code — он откроется холстом, а не текстом. Хочешь посмотреть, как он
устроен внутри, — переключись на исходник кнопкой в правом верхнем углу редактора.
