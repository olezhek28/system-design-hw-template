# Библиотека коробок

`sd-stencils.excalidrawlib` — набор готовых компонентов для схем: клиент, DNS, CDN,
балансировщик, шлюз, сервис, воркер, база, реплика, шард, кэш, объектное хранилище,
поисковый индекс, очередь, топик брокера, внешний сервис.

**Как подключить:** перетащи файл на холст Excalidraw. Коробки появятся в панели
библиотеки слева и останутся там для всех твоих схем.

**Цвет — это слой, а не украшение:**

| Цвет | Слой | Что кладём |
|---|---|---|
| 🔵 синий | вход и сеть | DNS, CDN, балансировщик, API Gateway |
| 🟢 зелёный | вычисление | сервисы, воркеры |
| 🟡 жёлтый | хранение | базы, реплики, шарды, кэш, объектное хранилище, индекс |
| 🔴 красный | асинхрон | очереди, топики, шина событий |
| ⚫ чёрный | вне системы | клиент, мобильное приложение, чужой сервис |

Смысл в том, что ментор (и интервьюер) читает схему с одного взгляда: где синхронный
путь запроса, где он уходит в асинхрон, что мы вообще не контролируем. Схема, где всё
одного цвета, читается вдвое дольше, а на собесе это твоё время.

Коробки не догма: не хватило — рисуй свою, но держи цвет по слою.
