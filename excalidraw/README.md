# Библиотека коробок

В `sd-stencils.excalidrawlib` лежат готовые компоненты для схем: клиент, DNS, CDN,
балансировщик, шлюз, сервис, воркер, база, реплика, шард, кэш, объектное хранилище,
поисковый индекс, очередь, топик брокера, внешний сервис.

Перетащи файл на холст excalidraw.com, и коробки появятся в панели слева. Один раз
перетащил, дальше они есть во всех твоих схемах. Открывать файл не нужно и не выйдет:
кликнешь, увидишь текст, потому что это библиотека, а не рисунок.

В VS Code с расширением Excalidraw подключать вообще ничего не надо, репозиторий несёт
настройку `excalidraw.workspaceLibraryPath`.

Цвет коробки говорит про слой:

- синий: вход и сеть, DNS, CDN, балансировщик, шлюз
- зелёный: вычисление, сервисы и воркеры
- жёлтый: хранение, базы и реплики, шарды, кэш, объектное хранилище, индекс
- красный: асинхрон, очереди и топики
- чёрный: то, что вне твоей системы, клиент или чужой сервис

Коробок не хватило, рисуй свою, только держи цвет по слою.
